# Çalışma kuralları

- Yalnızca `main` dalında çalış. Yan dal (branch) açma; değişiklikleri doğrudan `main`'e commit edip `main`'e push et.
- Push için sorma: iş bitince `main`'e push et. Push'tan önce `origin/main`'i çek; başka oturumdan gelen değişiklik varsa birleştir, çakışmaları çöz, sonra push et.
