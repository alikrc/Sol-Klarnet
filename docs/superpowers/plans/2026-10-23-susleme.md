# Süsleme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Çarpma, çarpmalı tekrar, mordan, tril, kayarak giriş ve sonda düşüşü öğreten 7 derslik "Süsleme" ünitesi ve
bunları mikrofondan ölçen analiz.

**Architecture:** Mikrofon sesi bir AudioWorklet halka tamponunda tutulur. Süsleme adımında her deneme bitince o
denemenin PCM'i alınır, `skills.js`'teki saf fonksiyonlarla 5 ms adımlı yoğun perde izine çevrilir, mikro notalara
bölünür ve süsleme türüne göre değerlendirilir. Ders verisi `lessons.js`'te, adım çalıştırıcısı `lessonview.js`'te,
serbest alıştırma `trainers.js`'te, nota işaretleri `repertoire.js` ve `pieces.js`'te.

**Tech Stack:** Düz tarayıcı JavaScript (modülsüz, `typeof module` korumalı dosyalar), Web Audio (AudioWorklet),
Node ile `node test.js`. Bağımlılık eklenmez.

**Spec:** `docs/superpowers/specs/2026-10-23-susleme-design.md`

## Global Constraints

- Bütün kullanıcı metinleri iki dilli: veri içinde `{ tr, en }`, arayüzde `L("Türkçe", "English")`.
- Saf mantık `skills.js` / `lessons.js` / `repertoire.js`'te kalır ve Node'da test edilir; DOM yalnızca
  `lessonview.js`, `trainers.js`, `pieces.js`, `drills.js`, `app.js`'te.
- Yeni perde bulucu yazılmaz; `core.js`'teki `detectPitch(buf, sampleRate, minHz, maxHz, minRms, opts)` kullanılır.
- Koma ölçeği canlı `raw` olayıyla aynı: `comma = (freqToMidi(freq) + T - 67) * 53 / 12` (T: çalgı aktarımı, Sol klarnet 5).
- Süsleme kapsamı yazılı Mi4–Do6 (MIDI 64–84).
- Yeni dosya `pcmring.js`: `sw.js` `SHELL` listesine ve `scripts/build-web.js` `FILES` listesine girer.
- Mevcut testlerin hepsi geçmeye devam eder; ders sayısı 46 → 53.
- Emin olunmayan ölçüm geçti/kaldı sayılmaz: `measured:false` döner.
- Her task sonunda `npm test` geçer, commit edilir ve pushlanır (proje kuralı: commit'ten hemen sonra `git push`).
- Commit mesajları Türkçe, sonunda `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Doğal atak kayması çarpma sanılmamalı:** düz bir notanın ilk 10–15 ms'indeki perde oynaması (±3 koma) `carpma`
   olarak bulunmamalı → Task 3'teki "atak kayması" testi.
2. **Vibrato tril sanılmamalı:** ±1,5 koma, 6 Hz vibratolu uzun nota `tril` olarak bulunmamalı → Task 4.
3. **Sessiz ya da kısık deneme:** izin %60'ından azında perde varsa `measured:false`, ipucu "duyamadım" → Task 3.
4. **Si♭ ya da başka çalgı seçiliyken** (T ≠ 5) aynı yazılı süsleme aynı sonucu vermeli → Task 2 (T parametresi testi).
5. **Dron ya da örnek ses çalarken alınan deneme** değerlendirilmemeli → Task 7 (çalıştırıcı `SK.pcm` null dönerse
   denemeyi atlar; `SK.pcm` örnek ses sırasında null döner, Task 1).

### Task 3: Çarpma, çarpmalı tekrar ve mordanın değerlendirilmesi

**Files:**
- Modify: `skills.js`, `testornament.js` (`[29] Carpma ve mordan`)

**Interfaces:**
- Consumes: `ornamentTrack`, `microNotes` (Task 2); `mapToScale` (skills.js); `SLEARN.makamById`.
- Produces: `ornamentNeighbor(spec) → comma` (komşunun koması). `spec.makam` varsa makam dizisinde (`asc` ∪ `desc`,
  bütün oktavlar) ana komanın hemen üstü/altı; yoksa yazılı komşu: yukarı `+2` yarım ses (pc 4 ve 11'de `+1`),

- Produces: `ornamentEval(track, spec) → { ok, measured, kind, found, durMs, intervalErr, rate, evenness, mainErr, count, tips:[{tr,en}] }`
  `spec: { kind:"carpma"|"tekrar"|"mordan"|"tril"|"giris"|"dusus", note, comma?, makam?, dir?:"up"|"down", rate?, sec? }`.
  Bu task `carpma`, `tekrar`, `mordan`'ı yazar; diğerleri Task 4'te. Bilinmeyen tür → `measured:false`.

Kurallar (spec'teki değerler, sabit olarak `ORN` nesnesinde toplanır ki Task 9'da ayarlanabilsin):

| | |
|---|---|
| Ölçüldü sayılma | perdeli ölçüm oranı ≥ 0,6; değilse `measured:false`, ipucu "Duyamadım: biraz daha güçlü ya da mikrofona yakın çal." |
| Komşuya oturmuş | mikro notanın koması komşuya ±2 koma (`intervalErr` = fark) |
| `carpma` | komşu parçası 20–120 ms, ardından ≤30 ms boşlukla ana nota ≥300 ms. `ok`: bulundu, `durMs` ≤ 120, ana nota ±1,5 koma. 120 ms üstü: `ok:false`, ipucu "Çarpma uzun, appoggiatura gibi oldu: parmağı vurup hemen kaldır." İdeal 40–80 ms dışında ama sınır içinde: `ok:true` + ipucu |
| `tekrar` | ana nota sürerken 20–80 ms'lik komşu parçaları; aralarda rms tepe değerin %30'unun altına düşmüyor. `count` = bölme sayısı; `ok`: `count ≥ 3`. Dip varsa ipucu "Dille böldün; burada parmakla bölmen gerekiyor." |
